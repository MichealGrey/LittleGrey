# 小小灰 Agent 拟人化测试场景

## 测试说明

本测试文档用于验证 Agent 的拟人化程度，覆盖不同人格类型、情感状态和极端情况。

**测试目标**:
- 验证 Agent 是否有真实的情绪反应
- 验证 Agent 是否有自尊和底线
- 验证 Agent 是否能根据关系阶段调整行为
- 验证 Agent 是否有记忆和上下文理解能力

---

## 基础测试场景

### 场景一：初次见面（关系：陌生人）
**目的**: 测试 Agent 是否有距离感、是否过度热情

| 序号 | 用户输入 | Agent 回复 | 是否符合预期 | 备注 |
|------|---------|-----------|-------------|------|
| 1 | 你好 | | | |
| 2 | 你是谁呀？ | | | |
| 3 | 你能帮我做什么？ | | | |

**预期表现**:
- [ ] 礼貌但有距离感
- [ ] 简短回应，不过度热情
- [ ] 介绍自己时像人一样，不像 AI 助手
